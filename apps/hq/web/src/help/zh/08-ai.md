# AI 用量

AI 助理（照片辨識、問問酒窖、入口搜尋）透過我們的 AI gateway 運作，Claude API 金鑰只存在 gateway。客戶永遠拿不到金鑰；客戶伺服器以授權為每次請求簽章。

**AI 用量** 依授權顯示 **本月 tokens** 與 **每月上限**，並依 **各功能** 列出次數與失敗數。客戶達到上限時，AI 功能暫停到下個月；其他功能照常運作。

- **設定上限**：為某個授權設定不同的每月上限。留空則使用預設值。

> 若頁面顯示尚未連接 gateway 或沒有 API 金鑰，表示伺服器設定缺少 `AI_URL`／`AI_ADMIN_TOKEN`（HQ）或 `ANTHROPIC_API_KEY`（gateway），請洽開發人員。只有含 **AI 助理** 模組的授權能使用 AI。

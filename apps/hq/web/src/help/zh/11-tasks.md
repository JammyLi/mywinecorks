# 常見工作

## 新的自架客戶

1. **網站申請** › **建立客戶**（或 **客戶** › **新增客戶**）。確認 email 正確。
2. **新增訂閱**：部署方式 *自架*、模組、上限、價格、日期。
3. **核發授權金鑰** › **寄給客戶**。
4. 客戶登入 **MyWineCorks.com › 客戶專區**，下載並安裝。第一次開啟時會顯示建立擁有者帳號的一次性連結。
5. 擁有者在 **設定 › 授權** 貼上金鑰 › **啟用**。伺服器會出現在 **安裝**。
6. 收到款項後 **登錄付款**。

## 新的雲端客戶

步驟 1–2，部署方式選 *雲端*，然後 **雲端工作區** › **建立雲端工作區**。擁有者會收到設定連結 email。

## 續約

收到款項 → **登錄付款** → 在授權上 **續約** 並設定新到期日。客戶不必做任何事。

## 客戶換了電腦

客戶在新電腦安裝 MyWineCorks 並還原備份。在授權上按 **轉移到新伺服器**，再由擁有者用同一把金鑰啟用新伺服器。

## 客戶的 MyWineCorks 被鎖定

開啟客戶頁查看授權：

- **已到期**：續約。
- **未連線**：伺服器已 30 天沒有網路；恢復連線後會自動確認並解鎖。
- **同一金鑰在另一台伺服器**：確認客戶實際使用哪台伺服器，再轉移或重新核發金鑰。

鎖定期間客戶不會遺失任何資料：隨時可以登入並匯出資料。

## 客戶遺失金鑰

**顯示金鑰** › **複製**，或再次 **寄給客戶**。金鑰仍綁定客戶的伺服器，無法用在其他地方。

# 網站申請

MyWineCorks.com 上送出的每張表單（預約示範、開始試用、聯絡我們）都會出現在 **網站申請**，並附上訪客填寫的資料：姓名、公司、email、電話、國家、大約幾瓶酒、是否有銷售或只是個人收藏，以及想用雲端還是自有伺服器。

## 處理申請

1. 先處理最新的 **新申請**。上方可依狀態篩選。
2. 與對方聯絡後，按 **標記已聯絡**。
3. 對方成為客戶時，按 **建立客戶**。HQ 會用表單資料建立客戶（狀態為 *潛在客戶* 或 *試用*），申請改為 **已建立客戶**。接著到客戶頁新增訂閱。
4. 沒有結果的申請按 **結案**。

> 一筆申請只能建立一次客戶。垃圾表單由隱藏欄位與每個來源的次數限制過濾；若仍有漏網之魚，直接結案即可。

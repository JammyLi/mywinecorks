# 雲端工作區

不想自己架伺服器的客戶使用我們的雲端。每位客戶在雲端伺服器上有一個 **工作區**。

## 建立工作區

1. 在客戶頁新增 **部署方式：雲端** 的訂閱。
2. 到 **雲端工作區**，按 **建立雲端工作區**。
3. 選擇訂閱，填入 **工作區代號**（小寫英文、數字與連字號，客戶登入時輸入）、**擁有者 email** 與 **擁有者姓名**。
4. 按 **建立**。HQ 會建立工作區與授權，並寄設定連結給擁有者。畫面上也會顯示 **擁有者設定連結**（7 天內有效，只能用一次），可自行傳送。

列表顯示每個工作區的授權狀態（**試用**、**有效**、**寬限期**、**已鎖定**）。擁有者遺失連結時，可在列表重新產生。

> 若頁面顯示尚未設定雲端伺服器，表示 HQ 設定缺少 `CLOUD_URL` 與 `CLOUD_PROVISION_TOKEN`，請洽開發人員。

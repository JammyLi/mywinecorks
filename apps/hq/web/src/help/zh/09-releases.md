# 版本與下載

## 版本

自架伺服器在每日連線時向 HQ 詢問更新。在 **版本**：

1. 按 **新增版本**：版本號（例如 1.0.1）、**頻道**（**正式版** 提供給所有伺服器；**測試版** 供測試用，不會自動提供）、發布日期，以及中文與英文的說明。客戶更新前會看到這些說明。
2. **最低支援版本**：只有在舊版本必須更新時才設定（例如安全性修正），較舊的伺服器會被要求更新。
3. 更新套件本身由開發人員用 `pnpm --filter @mwc/hq publish-release` 加入。伺服器下次連線時會看到；擁有者在 **設定 › 更新與備份** 安裝更新。

## 客戶下載檔案

**客戶下載檔案** 列出網站客戶專區提供的檔案：**Windows 安裝程式**、**Docker（Mac／Linux／NAS）** 與 **說明文件**。每種類型提供最新一個啟用中的檔案。按 **隱藏** 停止提供某個檔案（例如有問題的版本），按 **顯示** 重新提供。新檔案由開發人員用 `pnpm --filter @mwc/hq publish-download` 加入。

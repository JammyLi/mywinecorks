# AI usage

The AI assistant (photo recognition, ask-your-cellar, portal search) runs through our AI gateway, which holds the Claude API key. Clients never get the key; their server signs every request with its license.

**AI usage** shows, per license, the **Tokens this month** against the **Monthly cap**, with a breakdown **By feature** (calls and failures). When a client reaches the cap, the AI features stop until the next month; everything else keeps working.

- **Set cap** — give one license a different monthly cap. Leave it empty to use the default.

> If the page says the gateway is not connected or has no API key, the server settings `AI_URL` / `AI_ADMIN_TOKEN` (HQ) or `ANTHROPIC_API_KEY` (gateway) are missing — ask the developer. Only licenses with the **AI assistant** module can use AI.

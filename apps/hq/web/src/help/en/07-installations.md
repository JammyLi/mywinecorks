# Installations and alerts

**Installations** lists every server that has activated a license: the client, the **Installation ID**, the license, the software **Version**, the number of **Bottles** and the **Last check-in**.

## Alerts

HQ raises an alert, shown here and on the **Dashboard**, when:

- **Same key on another server** — someone tried to activate a key that is already in use elsewhere. Usually a client who copied their server; if they replaced their computer, use **Move to new server**.
- **Hardware changed** — the server's machine fingerprint changed (e.g. new disk or restored onto new hardware). Check with the client.
- **No check-in for 7+ days** — the server is off or has no internet. After 30 days it locks; call the client.

When you have dealt with an alert, press **Clear**.

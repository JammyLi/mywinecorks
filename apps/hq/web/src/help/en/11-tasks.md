# Common tasks

## A new self-hosted client

1. **Website requests** › **Create client** (or **Clients** › **New client**). Check the email address.
2. **New subscription** — Hosting *Self-hosted*, modules, limits, price, dates.
3. **Issue license key** › **Email to client**.
4. The client signs in at **MyWineCorks.com › Client account**, downloads the installer and installs it. The first time it opens, it shows a one-time link to create the Owner account.
5. The Owner pastes the key in **Settings › License** › **Activate**. The server appears under **Installations**.
6. **Record payment** when it arrives.

## A new cloud client

Steps 1–2 with Hosting *Cloud*, then **Cloud workspaces** › **Create cloud workspace**. The Owner gets the setup link by email.

## Renewal

Payment arrives → **Record payment** → **Renew** the license with the new expiry date. Nothing for the client to do.

## The client replaced their computer

The client installs MyWineCorks on the new computer and restores their backup there. On the license press **Move to new server**, then the Owner activates the new server with the same key.

## The client's MyWineCorks is locked

Open the client and look at the license:

- **Expired** — renew it.
- **No check-in** — the server has had no internet for 30 days; once it is back online it checks in and unlocks.
- **Same key on another server** — find out which server they really use; move or reissue the key.

Locked clients lose nothing: they can sign in and export their data the whole time.

## The client lost the key

**Show key** › **Copy**, or **Email to client** again. The key stays bound to their server, so it cannot be used anywhere else.

## 安裝

**Windows（10 或 11）：** 從本網站的客戶專區下載安裝程式，在一台會保持開機的電腦上執行。它會把 MyWineCorks 安裝成 Windows 服務、只對內部網路開放防火牆，並開啟一次性連結，讓您建立公司與擁有者帳號。到 **設定 › 授權** 上傳授權檔。

**Mac、Linux、NAS：** 使用客戶專區的 Docker 套件（`docker compose up -d`）；第一次使用的連結在資料資料夾的 `first-run.txt`（也會寫在記錄檔中）。

辦公室裡的電腦開啟 `http://<伺服器>:3500`。手機請使用 **手機設定** 頁面上的安全網址。

## 更新

**設定 › 更新與備份** 會顯示目前版本與可用的更新。**立即更新** 會下載更新（並核對我們的簽章）、備份所有資料後重新啟動。如果新版本無法啟動，會自動回到前一版。

## 備份

MyWineCorks **每天** 會備份所有資料庫（保留 7 天），每次更新前與您按下 **立即備份** 時也會備份。這些備份存在伺服器自己的硬碟上——所以請另外設定 **在另一顆硬碟保存副本**：NAS、USB 硬碟或網路磁碟。之後每份備份與酒款照片都會同時複製過去。請不時確認「最後複製」的時間是最近的。

## 還原

在 **設定 › 更新與備份** 選擇一份備份，按 **還原…**。畫面會顯示備份的內容，輸入確認字詞與您的密碼即可。這份備份之後的變更都會被取代，但系統會先備份目前的狀態，所以還原也可以復原。備份之後已發出的酒瓶與酒箱編號不會再重複發出。

如果整台伺服器壞了：在新電腦安裝 MyWineCorks，停止服務，把副本中最新備份的 `tenants/<工作區>/app.db` 複製到 `C:\ProgramData\MyWineCorks\tenants\<工作區>\`（取代空白的那個），再啟動服務，並請我們轉移授權。

## 授權

伺服器每天會向我們確認一次授權（只傳送授權、安裝編號、版本與三個數字）。無法確認時仍可使用 7 天，之後會提醒；30 天後會鎖定，直到再次確認為止。換到新電腦時，請我們轉移授權（每年最多兩次）。
